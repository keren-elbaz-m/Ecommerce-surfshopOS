# Product Roadmap

## Core Features (current state)

None — greenfield product.

## Phase 1: MVP

**Storefront**
- Home / landing page
- Catalog: browse, search, filter, sort
- Product detail pages
- Cart
- Checkout with mock payment
- Order confirmation

**Customer account**
- Sign up, login, logout
- Profile
- Order history

**Wishlist**
- Add / remove / view favorites

**Surfboard Finder**
- Guided questionnaire
- Personalized board recommendations

**Seller side**
- Login
- Dashboard
- Product, inventory, and order management

To be determined — nothing planned yet.
