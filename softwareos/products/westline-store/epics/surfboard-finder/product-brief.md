# Surfboard Finder — Product Brief

> Epic: epic.md · Product: ../../mission.md

## Goals

Beginner-to-intermediate surfers who've outgrown rentals want their own board but don't feel confident picking by technical spec (volume, length, shape) — they either guess wrong or don't buy. Goal: a guided questionnaire that translates their experience and preferences into a confident, personalized board recommendation from the real catalog.

## User Stories

- As a shopper, I can answer a short guided questionnaire (skill level, frequency, weight/height, wave conditions, budget) so the system understands my needs.
- As a shopper, I can see personalized board recommendations from the real catalog so I can trust the suggestion.
- As a shopper, I can view a recommended board's detail page or add it to cart directly so I can act on the recommendation.

## Success Criteria

- A shopper can complete the questionnaire and receive one or more board recommendations pulled from the real Strapi catalog (not hardcoded), each linking to a real product detail page where they can add it to cart.

## Out of Scope

- Seller dashboard / inventory management (Seller Dashboard epic)
- ML-based recommendations
- Saving/retaking past quiz results (unless trivial)
